# Vivan Sethi — Personal Portfolio

A responsive, static portfolio website built for the VAC-II personal branding capstone.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create a repository on GitHub (for example, `vivan-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and copy the generated URL into the capstone document.

## Before submitting
- Check that the LinkedIn and GitHub links open your profiles.
- Add repository links or live demos to individual project cards when ready.
- Update the skills and project descriptions to match your current work.
- The six social post images are clearly sample campaign visuals; they do not claim the posts were published.
- Progress bars are illustrative self-assessments, not formal results.
- Keep credentials, private contact information, and unverified performance metrics off the public site.

Brand palette: Navy `#17365D` / deep navy background, teal `#00A6A6`, white, and light grey.
